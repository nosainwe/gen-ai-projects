# My generated results

A dry run only writes the control maps (`*_control.png`). A real `--generate` run on a GPU adds the 15 images, the comparison sheets (`*_comparison.png`, `*_prompts.png`), `run_manifest.json`, `run_summary.csv`, `environment.json` and `human_review_template.csv`, where I record my own ratings.

Every image here comes from a real model run. The fake pipeline in `tests/` never writes to this folder.
